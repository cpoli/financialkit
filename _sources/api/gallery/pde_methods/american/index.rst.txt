American options
----------------

Early exercise turns each implicit step into a linear complementarity
problem: projected SOR, the Brennan-Schwartz direct solve and the
penalty method.

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="An American option is either held, where it satisfies the Black-Scholes equation, or exercised, where it equals its payoff; each implicit step becomes a linear complementarity problem Ax \ge b,\ x \ge g,\ (Ax - b)^\top(x - g) = 0. Colin Cryer (1971) solved it by successive over-relaxation, projecting each update back onto x \ge g. psor does this inside CrankNicolson; the sweep count depends strongly on the relaxation parameter \omega.">

Because the put is exercised on a single interval at the bottom of the grid, this one pass solves the complementarity problem exactly. brennan_schwartz matches PSOR to rounding at a fraction of the cost.">

The resulting nonlinear system is solved by a Newton (policy) iteration that only changes which nodes are penalised, and converges in two or three tridiagonal solves per time step, independently of the grid size -- unlike PSOR, whose sweep count grows as the grid is refined. penalty_solve implements it.">
