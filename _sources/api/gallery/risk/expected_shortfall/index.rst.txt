Expected shortfall and coherence
--------------------------------

What makes a risk measure coherent, why VaR is not, and how expected
shortfall is estimated and allocated to positions.

    <div class="sphx-glr-thumbcontainer" tooltip="Artzner, Delbaen, Eber and Heath (1999) listed four properties a capital requirement should have: monotonicity, subadditivity, positive homogeneity and translation invariance. VaR fails subadditivity: two desks can each look safe while their merger needs capital. The classic counterexample is a pair of independent bonds that each default with 4% probability. At 95% neither default is in the tail, so each bond&#x27;s VaR is negative; together, a default happens with probability 7.8%, and the portfolio&#x27;s VaR is a loss.">
