Examples#

This gallery walks through every public feature of financialkit.monte_carlo: crude Monte Carlo with error bars, variance reduction, quasi-Monte Carlo, Monte Carlo Greeks and multilevel Monte Carlo. Each script illustrates one dated breakthrough from the history page.

Each script in this gallery is self-contained and can be run directly with python examples/monte_carlo/<section>/<script>.py.

Sections#

  • basics – the Monte Carlo method of Metropolis and Ulam, Box-Muller normal variates and Boyle’s option prices.

  • variance_reduction – Neyman stratification, importance sampling, antithetic variates, Latin hypercube sampling, control variates and moment matching.

  • quasi_monte_carlo – Halton and Sobol sequences, the Koksma-Hlawka inequality, Owen scrambling, Paskov-Traub’s high-dimensional integrals and the Brownian bridge.

  • greeks – likelihood-ratio and pathwise Greeks.

  • multilevel – Giles’s multilevel Monte Carlo.
