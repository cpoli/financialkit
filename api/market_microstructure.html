financialkit.market_microstructure.almgren_chriss(X, T, n_steps, sigma, eta, risk_aversion, gamma=0.0, epsilon=0.0)[source]#

Almgren-Chriss efficient liquidation of X shares over [0, T].

Minimising \(E + \lambda V\) gives

\[x_j = X\,\frac{\sinh(\kappa (T - t_j))}{\sinh(\kappa T)}, \qquad \cosh(\kappa\tau) = 1 + \frac{\lambda\sigma^2\tau^2}{2\tilde\eta},\]

so \(1/\kappa\) is the half-life of the trade: a risk-neutral trader (\(\lambda = 0\)) sells evenly, and a very risk-averse one sells almost everything at once.

Parameters:

  • X (float) – Shares to sell.

  • T (float) – Horizon.

  • n_steps (int) – Number of trading intervals \(N\).

  • sigma (float) – Price volatility per unit time (price units).

  • eta (float) – Temporary impact per unit of trading rate.

  • risk_aversion (float) – \(\lambda \ge 0\).

  • gamma (float) – Permanent impact and fixed cost per share.

  • epsilon (float) – Permanent impact and fixed cost per share.

Return type:

ExecutionResult

Returns:

ExecutionResult

Examples

>>> almgren_chriss(10.0, 1.0, 5, sigma=0.3, eta=0.05, risk_aversion=0.0).holdings.round(6).tolist()
[10.0, 8.0, 6.0, 4.0, 2.0, 0.0]

financialkit.market_microstructure.bertsimas_lo(shares, n_periods, theta, gamma=0.0, rho=0.0, sigma_eta=0.0, x0=0.0, signals=None, p0=0.0)[source]#

Bertsimas and Lo’s optimal schedule for buying shares over n_periods.

The execution price follows \(P_k = P_{k-1} + \theta S_k + \gamma X_k + \varepsilon_k\) with a serially correlated signal \(X_k = \rho X_{k-1} + \eta_k\), and the trader minimises \(E[\sum_k P_k S_k]\) subject to \(\sum_k S_k = \bar S\). The value function is quadratic, and backward induction gives

\[\delta_{w,k} = 1 - \frac{\theta}{2a_{k+1}}, \quad \delta_{x,k} = \frac{\rho b_{k+1}}{2a_{k+1}}, \quad a_k = \theta - \frac{\theta^2}{4a_{k+1}}, \quad b_k = \rho\left(\gamma + \frac{\theta b_{k+1}}{2a_{k+1}}\right),\]

from \(a = \theta\), \(b = \gamma\rho\) in the last period. With \(\gamma = 0\) the policy is \(S_k = W_k / (T - k)\), an even split, and the expected cost is \(P_0\bar S + \theta \bar S^2 (T + 1) / (2T)\).

Parameters:

  • shares (float) – \(\bar S\).

  • n_periods (int) – \(T\).

  • theta (float) – Permanent impact per share.

  • gamma (float) – Signal loading, persistence and innovation volatility.

  • rho (float) – Signal loading, persistence and innovation volatility.

  • sigma_eta (float) – Signal loading, persistence and innovation volatility.

  • x0 (float) – Signal observed before the first trade, \(X_{-1}\).

  • signals (ArrayLike | None) – Realised \(X_{k-1}\) before each trade; the expected path \(\rho^k x_0\) if omitted.

  • p0 (float) – Price before trading.

Return type:

BertsimasLoResult

Returns:

BertsimasLoResult

Examples

>>> res = bertsimas_lo(1000.0, 4, theta=1e-4)
>>> res.trades.round(9).tolist(), round(res.expected_cost, 6)
([250.0, 250.0, 250.0, 250.0], 62.5)

financialkit.market_microstructure.corwin_schultz_spread(high, low, clip=True)[source]#

Corwin-Schultz relative spread from each pair of consecutive days’ highs and lows.

The variance in a day’s high-low range grows with the horizon but the spread does not, so comparing one two-day range with two one-day ranges separates them:

\[\alpha = \frac{\sqrt{2\beta} - \sqrt\beta}{3 - 2\sqrt2} - \sqrt{\frac{\gamma}{3 - 2\sqrt2}}, \qquad S = \frac{2(e^\alpha - 1)}{1 + e^\alpha},\]

with \(\beta\) the sum of the two squared daily log ranges and \(\gamma\) the squared two-day log range.

Parameters:

  • high (ArrayLike) – Daily highs and lows.

  • low (ArrayLike) – Daily highs and lows.

  • clip (bool) – Set negative two-day estimates to zero, as Corwin and Schultz do before averaging.

Return type:

ndarray

Returns:

ndarray, shape (n - 1,) – Average over a month for a monthly estimate.

Examples

financialkit.market_microstructure.glosten_milgrom_quotes(belief, alpha, v_low, v_high, eta=0.5)[source]#

Zero-profit bid and ask when a fraction alpha of traders know the value.

The value is \(V_H\) with probability \(\theta\) (the belief) and \(V_L\) otherwise. An informed trader buys when it is high and sells when it is low; an uninformed one buys with probability \(\eta\). Then

\[a = E[V \mid \text{buy}] = V_L + (V_H - V_L)\, \frac{\theta(\alpha + (1-\alpha)\eta)}{\theta\alpha + (1-\alpha)\eta},\]

and the bid is the same with a sell.

financialkit.market_microstructure.ho_stoll_quotes(value, inventory, alpha, beta, risk_aversion, sigma, tau=1.0)[source]#

Optimal bid and ask of a risk-averse dealer, a one-period Ho-Stoll model.

Orders arrive at \(\lambda = \alpha - \beta\delta\) on each side, \(\delta\) being the distance of the quote from the true value \(p\). The dealer maximises expected trading profit minus \(\tfrac{\gamma}{2}\sigma^2\tau\) times the squared end-of-period inventory. The first-order conditions give Ho and Stoll’s two results:

\[\delta_a + \delta_b = \frac{\alpha}{\beta}, \qquad \frac{a + b}{2} = p - \frac{\kappa I}{2(1 + \kappa\beta)}, \quad \kappa = \gamma\sigma^2\tau:\]

the spread does not depend on inventory, and the quotes slide down when the dealer is long.

Parameters:

  • value (ArrayLike) – True value \(p\).

  • inventory (ArrayLike) – Dealer’s inventory \(I\).

  • alpha (float) – Intercept and slope of the order-arrival rate.

  • beta (float) – Intercept and slope of the order-arrival rate.

  • risk_aversion (float) – \(\gamma \ge 0\).

  • sigma (float) – Volatility of the value, per unit time.

  • tau (float) – Holding horizon.

Return type:

tuple[ndarray, ndarray]

Returns:

bid, ask (ndarray)

Examples

>>> b, a = ho_stoll_quotes(100.0, [-10, 0, 10], alpha=10.0, beta=20.0, risk_aversion=0.1, sigma=0.2)
>>> (a - b).round(6).tolist(), ((a + b) / 2).round(4).tolist()
([0.5, 0.5, 0.5], [100.0185, 100.0, 99.9815])

financialkit.market_microstructure.simulate_garman(stock, cash, ask, bid, buy_rate, sell_rate, n_events, n_paths=1, rng=None)[source]#

Simulate Garman’s dealer event by event until stock or cash runs out.

A buy order (rate \(\lambda_a\)) takes one share at the ask; a sell order (rate \(\lambda_b\)) delivers one at the bid. The dealer fails when the stock is zero or the cash cannot pay the bid.
