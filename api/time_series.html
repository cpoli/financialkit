financialkit.time_series#

financialkit.time_series hub · History · Examples · API reference

Returns and their stylized facts (the Hill tail index, moments and the Jarque-Bera test); tests of the random walk (serial correlation, Fama’s runs test, Box-Pierce and Ljung-Box, Lo-MacKinlay variance ratios); Yule-Walker autoregressions (scipy.linalg.solve_toeplitz), partial autocorrelations, ARMA simulation (scipy.signal.lfilter) and conditional maximum likelihood (scipy.optimize.least_squares) with AIC/BIC order selection; the augmented Dickey-Fuller and Engle-Granger tests with MacKinnon’s critical values; Hurst’s rescaled range and fractional Gaussian noise; ARCH, GARCH, EGARCH, GJR-GARCH and RiskMetrics EWMA volatility models fitted by maximum likelihood (scipy.optimize.minimize), Engle’s ARCH-LM test, Parkinson’s range estimator and realized variance.

financialkit.time_series: returns, efficiency tests, ARMA, unit roots, long memory and volatility.

Returns and their stylized facts (fat tails by the Hill estimator, the Jarque-Bera test via scipy.stats.jarque_bera()); tests of the random walk (serial correlation by scipy.fft, Fama’s runs test, Box-Pierce and Ljung-Box, Lo-MacKinlay variance ratios); Yule-Walker autoregressions (scipy.linalg.solve_toeplitz()), partial autocorrelations, ARMA simulation (scipy.signal.lfilter()) and conditional maximum likelihood (scipy.optimize.least_squares()) with AIC/BIC order selection; the augmented Dickey-Fuller and Engle-Granger tests with MacKinnon’s critical values; Hurst’s rescaled range and fractional Gaussian noise; and ARCH, GARCH, EGARCH, GJR-GARCH and RiskMetrics EWMA volatility models fitted by maximum likelihood (scipy.optimize.minimize()), Engle’s ARCH-LM test, Parkinson’s range estimator and realized variance.

Returns are decimals per period and variances are per period; annualize with financialkit.constants.TRADING_DAYS_PER_YEAR.

class financialkit.time_series.ARCH(omega, alpha, mu=0.0)[source]#

Bases: VolatilityModel

Engle’s (1982) ARCH(1): \(\sigma_t^2 = \omega + \alpha\,\varepsilon_{t-1}^2\).

Covariance stationary when \(\alpha < 1\), with kurtosis \(3(1-\alpha^2)/(1-3\alpha^2)\) for \(\alpha^2 < 1/3\): the model fattens the tails of returns even with normal innovations.

class financialkit.time_series.EGARCH(omega, alpha, gamma, beta, mu=0.0)[source]#

Bases: VolatilityModel

Nelson’s (1991) exponential GARCH(1,1).

\[\ln\sigma_t^2 = \omega + \beta\ln\sigma_{t-1}^2 + \alpha\bigl(|z_{t-1}| - E|z|\bigr) + \gamma z_{t-1}, \qquad z_t = \varepsilon_t / \sigma_t\]

The log form keeps the variance positive with no sign restrictions, and \(\gamma < 0\) makes negative returns raise volatility more than positive ones. Stationary when \(|\beta| < 1\).

Examples

>>> m = EGARCH(omega=-0.2, alpha=0.15, gamma=-0.08, beta=0.98)
>>> bool(m.news_impact(-0.02, 1e-4) > m.news_impact(0.02, 1e-4))
True

class financialkit.time_series.EWMA(lam=0.94)[source]#

Bases: VolatilityModel

RiskMetrics (1994) exponentially weighted moving average variance.

\[\sigma_t^2 = \lambda\,\sigma_{t-1}^2 + (1 - \lambda)\,r_{t-1}^2\]

an integrated GARCH(1,1) with \(\omega = 0\) and zero mean. RiskMetrics fixed \(\lambda = 0.94\) for daily and \(0.97\) for monthly data across all assets; fit() estimates it instead. With no mean reversion, the forecast at every horizon is today’s variance.

Parameters:

lam (float) – Decay factor in (0, 1); the effective memory is about \(1/(1-\lambda)\) periods.

Examples

>>> EWMA(0.94).variance([0.01, -0.02, 0.0], v0=1e-4).round(8).tolist()
[0.0001, 0.0001, 0.000118]

class financialkit.time_series.GARCH(omega, alpha, beta, mu=0.0)[source]#

Bases: VolatilityModel

Bollerslev’s (1986) GARCH(1,1): \(\sigma_t^2 = \omega + \alpha\,\varepsilon_{t-1}^2 + \beta\,\sigma_{t-1}^2\).

class financialkit.time_series.GJRGARCH(omega, alpha, gamma, beta, mu=0.0)[source]#

Bases: VolatilityModel

Glosten-Jagannathan-Runkle (1993) GARCH with a leverage term.

\[\sigma_t^2 = \omega + (\alpha + \gamma\,\mathbf 1\{\varepsilon_{t-1} < 0\})\,\varepsilon_{t-1}^2 + \beta\,\sigma_{t-1}^2\]

With symmetric innovations the persistence is \(\alpha + \gamma/2 + \beta\). \(\gamma > 0\) makes bad news raise volatility more than good news of the same size.

Examples

>>> m = GJRGARCH(omega=1e-6, alpha=0.02, gamma=0.1, beta=0.9)

class financialkit.time_series.VolatilityModel[source]#

Bases: ABC

A conditional-variance model \(r_t = \mu + \sigma_t z_t\), \(z_t \sim N(0, 1)\).

Subclasses define their parameters (param_names), the one-step update news_impact(), the bounds and constraints of estimation, and how the parameters change when returns are rescaled. Variance filtering, the log-likelihood, simulation and maximum-likelihood fitting are shared. The pre-sample variance is the sample variance of the demeaned returns (“backcasting”).

classmethod fit(returns)[source]#

Maximum-likelihood estimate on returns (Gaussian quasi-likelihood).

The returns are scaled to unit variance before optimizing (so every parameter is of order one) and the estimate is mapped back, which the Gaussian likelihood allows because each model family is closed under rescaling. scipy.optimize.minimize() (SLSQP) handles the bounds and stationarity constraints.

financialkit.time_series.runs_test(x)[source]#

Fama’s (1965) runs test on the signs of price changes.

A run is a maximal sequence of changes with the same sign (+, - or 0). With \(n_i\) changes of sign \(i\) out of \(N\), the number of runs under independence has mean and variance

\[m = \frac{N(N+1) - \sum_i n_i^2}{N}, \qquad \sigma_m^2 = \frac{\sum_i n_i^2\bigl[\sum_i n_i^2 + N(N+1)\bigr] - 2N\sum_i n_i^3 - N^3}{N^2(N-1)}.\]

Too few runs means positive dependence (trends), too many means reversals. The statistic is the normal approximation with a half-run continuity correction; with two signs it reduces to the Wald-Wolfowitz test.

financialkit.time_series.variance_ratio(log_prices, q=(2, 4, 8, 16))[source]#

Lo-MacKinlay (1988) variance-ratio test of the random walk.

If log prices follow a random walk, the variance of q-period returns is q times that of one-period returns. With overlapping q-period returns and both variances bias-corrected,

\[VR(q) = \frac{\hat\sigma_c^2(q)}{\hat\sigma_a^2}, \qquad z(q) = \frac{VR(q) - 1}{\sqrt{2(2q-1)(q-1)/(3qT)}},\]

and the heteroskedasticity-consistent \(z^*(q) = \sqrt T\,(VR(q)-1)/\sqrt{\hat\theta(q)}\) with \(\hat\theta(q) = \sum_{j=1}^{q-1} [2(q-j)/q]^2 \hat\delta(j)\) stays valid under volatility clustering (Lo and MacKinlay 1988, eqs. (12)-(14) and Theorem 3). Since \(VR(q) - 1 \approx 2\sum_{k<q}(1-k/q)\rho_k\), positive autocorrelation pushes the ratio above one.

Parameters:

  • log_prices (array_like, shape (T + 1,))

  • q (int or sequence of int) – Horizons, each at least 2.

Return type:

VarianceRatioResult

Returns:

VarianceRatioResult

Examples

>>> import numpy as np
>>> p = np.cumsum(np.random.default_rng(3).standard_normal(5001))
>>> res = variance_ratio(p, q=[2, 4])
>>> bool(np.all(np.abs(res.z) < 3))
True
financialkit.time_series.yule_walker(x, order, demean=True)[source]#

Fit an AR(order) model by solving the Yule-Walker equations.

The equations \(\rho_k = \sum_{i=1}^p \phi_i \rho_{k-i}\), k = 1..p, form a Toeplitz system in the sample autocorrelations, and \(\sigma^2 = \hat\gamma_0 (1 - \sum_i \phi_i \hat\rho_i)\). Yule’s (1927) sunspot fit was \(\phi_1 \approx 1.34\), \(\phi_2 \approx -0.65\).

Parameters:

  • x (array_like)

  • order (int)

  • demean (bool) – Subtract the sample mean first.

Return type:

ARMAResult

Returns:

ARMAResult – With ma empty; the log-likelihood is conditional on the first order values.

Examples

>>> import numpy as np
>>> x = simulate_arma(ar=[1.34, -0.65], n=50_000, rng=0)
>>> yule_walker(x, 2).ar.round(2).tolist()
[1.34, -0.65]
