financialkit.datasets
=====================

Small real datasets bundled with the package and loaded as numpy arrays:
Robert Shiller's monthly S&P composite data since 1871, Kenneth French's
daily market and monthly factor returns and his 25 size by
book-to-market portfolios, and month-end Treasury yields from FRED. The
empirical gallery examples (fat tails, the Hill estimator, GARCH,
Shiller's excess volatility, the equity premium puzzle, Fama-French and
yield-curve PCA) run on them. Nothing is downloaded at run time;
``financialkit/datasets/README.md`` lists each file's source and terms.
